# Krunchy Vadawale & Bilingual Recipe Scaler

Welcome to the **Krunchy** repository!

## 📦 What's Inside

1. **`recipe-scaler/`**
   - **Bilingual Recipe Scaler (English & Marathi - मराठी)**
   - Built with **React 19**, **Tailwind CSS**, and **Firebase Cloud Firestore**.
   - Features:
     - 🌐 Instant bilingual UI toggle (English ⇄ Marathi).
     - ⚡ Real-time servings multiplier (presets 1, 2, 4, 6, 8, custom decimal scaling like 1.5).
     - 🍲 Preloaded authentic Maharashtrian recipes (Kanda Poha, Chai, Misal Pav, Puran Poli, Batata Vada, Sabudana Khichdi).
     - 🔥 Firebase Cloud Firestore integration (`krunchy-b0b61`) for saving and syncing recipes.
     - 📱 Native mobile card app layout with shopping checklist and fraction/decimal formats.
   - To run:
     ```bash
     cd recipe-scaler
     npm install
     npm run dev
     ```

2. **Brand Assets & Menu**
   - `MENU/` – Brand menus, posters, and specials.
   - `product photo/` – Product photography (Crispy Cheesy Vadapav, Krunchy VadaPav, etc.).
   - `Krunchy Vadawale Loyalty Card.pdf` – Customer loyalty card design.
